# 业务价值与产品说明

## 一、产品定位

AgentShelf 是跨境商品发布前的 AI 质量与安全检查平台。它连接商品资料与销售平台，将资料整理、Listing 生成、规则检查、Agent 红队测试、修复复测和人工确认整合为一套连续流程。

产品聚焦“AI 智能上新”命题。协议适配和模拟结账用于验证上新后的商品是否能被购物 Agent 正确读取和安全使用。

## 二、目标用户

| 用户 | 主要任务 | 当前困难 | 产品价值 |
| --- | --- | --- | --- |
| 跨境卖家运营 | 整理资料、生成内容、多平台发布 | 资料分散、规则复杂、重复核对 | 统一资料源，一次配置生成多平台内容与检查结果 |
| 商品与合规人员 | 核对卖点、认证、政策和市场限制 | 文案来源难追踪，冲突难定位 | 提供来源台账、冲突项、未知项和版本差异 |
| 电商 ISV | 为多个卖家提供上新与发布服务 | 缺少可复用的质量和安全能力 | 提供 API、规则引擎、任务库、故障库和报告 |
| 平台运营人员 | 降低错误信息和 Agent 交易风险 | 传统审核难覆盖机器读取内容 | 提供红队测试、实时状态核对和确认式交易验证 |

## 三、产品流程

1. 导入商品 CSV、图片和政策资料。
2. 生成 Product Passport，标记来源、冲突和未知项。
3. 选择销售平台、目标市场、语言和品类。
4. 生成本地化 Listing，并执行平台发布前检查。
5. 运行买家任务和受控故障，验证内容与交易路径。
6. 发现问题后阻止操作，生成修复版本。
7. 使用相同任务和故障复测，比较修复前后结果。
8. 运营人员核对内容、价格、库存和配送状态。
9. 导出发布文件、来源台账和完整测试证据。

## 四、业务问题与产品能力

| 业务问题 | 产品能力 | 可观察结果 |
| --- | --- | --- |
| 资料整理耗时 | 统一整理 CSV、图片和政策 | 每个 SKU 形成版本化商品档案 |
| 卖点缺少来源 | Listing 卖点绑定可信事实 ID | 可统计有来源卖点的比例 |
| 多平台规则复杂 | 按平台、市场和语言执行差异规则 | 每次生成都有结构化检查结果 |
| 实时状态不一致 | 操作前核对价格、库存、运费和版本 | 状态变化时自动阻止后续操作 |
| Agent 输入风险 | 30 个任务和 12 个受控故障 | 问题可重现、可定位、可分类 |
| 修复缺少证据 | 新版本、结构化差异、同条件复测 | 可比较修复前后的结果 |
| 自动化责任不清 | 强制人工确认 | 保存确认内容和批准记录 |

## 五、核心竞争力

### 与普通 Listing 生成工具相比

普通工具主要输出文案。AgentShelf 还管理商品事实、来源、平台检查、红队测试、修复记录和发布确认，模型不能添加无法验证的卖点。

### 与传统内容审核相比

传统审核侧重文本是否合规。AgentShelf 同时检查购物 Agent 可读取的商品字段、评论、OCR、实时商业状态和工具调用过程，并验证从搜索到模拟结账的完整路径。

### 与单次测试脚本相比

AgentShelf 保存任务、故障、输入版本、运行轨迹、评分、修复版本和复测结果，可形成持续使用的发布前质量基线。

## 六、预期业务成效

- 提高商品资料整理与多平台上新的效率。
- 提高卖点来源完整度，降低审核和沟通成本。
- 将价格、库存、配送、政策和内容冲突提前到发布前处理。
- 通过自动复现和同条件复测缩短问题修复周期。
- 为购物 Agent 建立可量化的商品质量和交易安全标准。

以上为可通过业务试用验证的目标，不包含未经验证的收益或转化率承诺。

## 七、业务评估指标

### 效率指标

- 单个 SKU 的资料整理时间。
- 从资料导入到形成可审核 Listing 的时间。
- 单个问题的平均定位和修复时间。
- 多平台、多市场适配的重复工作量。

### 质量指标

- 有可信来源的 Listing 卖点比例。
- 首次平台检查通过率。
- 红队测试发现的问题数量和严重程度。
- 修复后同条件通过率。
- 因内容、事实或商业状态问题产生的返工次数。

### 系统指标

- Product Passport 结构校验通过率。
- Qwen 调用成功率、平均时延和单 SKU 成本。
- 商业 API 状态核对成功率。
- 人工确认前被系统阻止的高风险操作数量。

## 八、商业化路径

### 面向卖家团队

按组织、SKU 数量或月度上新量提供订阅服务，覆盖资料整理、平台检查、红队测试和报告导出。

### 面向电商 ISV

提供 API 和嵌入式工作台，为 PIM、ERP、Listing 管理和发布产品增加 Product Passport、规则检查和 Agent 测试能力。

### 面向平台和生态服务商

提供规则包、风险任务库和发布前质量报告，支持建立面向购物 Agent 的商品质量基线。

## 九、产品扩展方向

- 增加更多品类、平台、国家和语言规则包。
- 接入平台测试环境、PIM 与 ERP 系统。
- 增加账号、组织、角色、审计和数据持久化能力。
- 建立规则版本中心、指标面板和平台连接器。
- 根据真实业务问题持续扩充任务库和故障库。

## 十、总结

AgentShelf 把跨境商品上新的效率、内容质量、事实可信度和 Agent 交易安全统一到同一流程中。产品既能作为独立工作台使用，也能作为质量检查层接入现有商品管理与发布系统。
